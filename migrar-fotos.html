📦 Mover as fotos dos produtos para o Storage

Hoje as fotos estão guardadas dentro do banco de dados, e todo cliente que abre a loja baixa todas elas de uma vez. Esta página leva cada foto para o Storage (uma pasta de arquivos) e deixa no produto só o link. Nenhum produto é apagado: só o campo da foto passa a apontar para o arquivo, e cada foto só é trocada depois de conferida.

Pode rodar de novo quantas vezes quiser: o que já foi movido é ignorado.
